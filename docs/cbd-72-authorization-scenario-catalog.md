## 1. Purpose and assertion contract

This catalog supplies deterministic acceptance evidence for the CBD-72 permission model. Every completed scenario must state the actor and active membership, budget space, target resource and scope, initial versions, action, expected visible result, protected-state delta, audit outcome, and notification outcome.

A denied scenario passes only when the action is unavailable in the interface, a direct request is denied server-side, protected state is unchanged, no restricted data is returned or inferred, and a safe audit event is recorded.
